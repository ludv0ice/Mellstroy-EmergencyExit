# Проверка версии 0.1

Дата: 12 октября 2026. Движок браузера: установленный Microsoft Edge / Chromium, чистый профиль автоматизации. Основное разрешение — 1366×768; интерфейс дополнительно проверен при 390×844.

- `npm.cmd test`: 13 успешных тестов. Проверены адаптер GML-данных, боезапас, столкновения быстрых пуль, оружие-бросок, добивание, стены и зрение, двери, перехват оружия, навигация, целостность всех импортированных комнат/текстур, размеры/кадры/origin новых ассетов и SHA-256 исходных PNG.
- `npm.cmd run build`: успешная production-сборка Vite. Phaser создаёт большой JS-файл; Vite выводит предупреждение о размере чанка, не ошибку сборки.
- Готовая сборка обслуживалась `vite preview` на порту 4173: загрузились меню и ассеты, ошибок JavaScript не обнаружено.
- Через интерфейс архива последовательно загружены все 67 боевых комнат; в каждой проверено наличие игровой симуляции и HUD. Ошибок JavaScript не обнаружено. Детали — `browser-rooms.json`.
- Учебная глава пройдена вводом клавиатуры и мыши: подбор оружия, атака, поражение всех трёх противников, выход и экран результатов.
- Полностью пройдена двухэтажная глава вокзала: `rmTrainstationEntrance` → `rmTrainstationDownstairs` → `rmTrainstationEntrance` → машина → результаты. Боезапас перенёсся между этажами: 30 → 22 → 2. Детали — `campaign-playtest.json`.
- Проверены смерть и клавиатурный перезапуск, пауза, поиск комнат, окно настроек и сохранение прогресса.
- На узком экране исправлено обрезание заголовка; горизонтального переполнения меню и настроек нет. Сенсорное прохождение кампании не проверялось.

Геометрический аудит показывает группы противников, недоступные пешком без учёта стрельбы через стекло в `rmOfficeFloor2`, `rmPoliceHQFloor3`, `rmNew6`. В исходных картах они находятся за стеклянными перегородками. Разрушение/прострел стекла реализованы; полного прохождения этих трёх карт не проверяли.

Это проверка фактической версии, не доказательство точного соответствия оригиналу. Все главы целиком и оригинальные сценарные события не проверены и не заявляются как перенесённые 1:1. Полные ограничения перечислены в README и `port-audit.json`.
