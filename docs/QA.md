# Проверка компактной версии

Дата: 13 октября 2026. Node.js 24.19.0, Chromium 154.0.8037.57. Проверены сервер разработки Vite и production-сборка; снимки интерфейса просмотрены при 1366×768 и 390×844.

## Размеры

| Состав | До | После |
|---|---:|---:|
| Файлы проекта без `.git`, зависимостей и сборки | 380,1 МБ | около 10,4 МБ |
| `public/` | 47,0 МБ | 10,1 МБ |
| Готовая веб-игра `dist/` | около 48,5 МБ | 11,7 МБ |
| ZIP готовой веб-игры | — | 3,8 МБ |

Значения указаны в десятичных мегабайтах. ZIP содержит `index.html` и `assets/`; проверены целостность архива и отсутствие GML. Игра по-прежнему запускается через HTTP-сервер.

Удалены архив исходного GameMaker-проекта, дубли текстур, промежуточные изображения генерации, неиспользуемые карты и звуки. Сохранены все 22 главы, 48 комнат кампании и сцена меню. Текстуры, 22 звука и шрифт не перекодировались. История Git сохранена и всё ещё содержит старые файлы; размер полного клонирования этой проверкой не уменьшен.

## Автоматические проверки

- `npm test`: 18 тестов, все прошли; пропущенных и отключённых нет. Включены проверки загрузки встроенных ресурсов без сети и сохранения ошибок HTTP в режиме разработки.
- `npm run build`: успешно. Сохраняется предупреждение Vite о большом JS-файле Phaser.
- `npm run check:assets`: успешно. Проверены 49 комнат, 453 записи спрайтов, 22 звука, ссылки на ассеты, отсутствие лишних файлов в поставке и лимит 100 МБ. Точные размеры: `publicBytes = 10119026`, `buildBytes = 11669094`.
- Регрессионные значения в `tests/fixtures/campaign-baseline.json` сняты до преобразования данных. Проверены геометрия, трансформации и порядок отрисовки всех 49 комнат, совпадение детерминированных последовательностей симуляции и поведение всех 24 модификаторов.
- SHA-256 всех оставленных текстур, звуков и шрифта совпадает с версией до сокращения.
- Игровые полотна всех 48 комнат кампании сравнены со снимками до изменений: **48 из 48 совпали попиксельно** при фиксированном времени отрисовки.
- Стили существующих экранов сохранены; исключены только селекторы удалённого архива. Скриптовый адаптер заменён загрузкой обычного JSON.

## Проверки браузера

- На dev-сервере и в production-сборке загрузились меню, учебная комната и ассеты; проверены пауза и продолжение. Ошибок JavaScript и загрузки игровых ассетов нет.
- В меню осталось три пункта. Кнопка «Карты из GMX», панель архива и обработчики удалены. Выбор 22 глав и настройки работают.
- Через события клавиатуры и мыши проверены движение, подбор дробовика, расход патрона при выстреле, бросок и перезапуск с исходным состоянием комнаты.
- Все 22 WAV успешно декодированы браузерным AudioContext.
- На двухэтажной главе вокзала проверены переход вниз, перенос оружия/17 патронов/брони, возвращение к сохранённому очищенному этажу, посадка в машину, экран результатов и сохранение продолжения в `localStorage`. Для этой проверки враги удалялись через методы симуляции: это проверка переходов и состояния, а не полное прохождение главы игроком.
- Меню и HUD просмотрены на узком экране. Полное сенсорное прохождение не проверялось.

`favicon.ico` по-прежнему отсутствует и может вернуть 404; это не игровой ассет. Проверки не доказывают полного прохождения каждой главы или точного соответствия оригинальным сценарным событиям Hotline Miami.

## Автономный запуск без Node.js

`npm run build:standalone` сформировал корневой `index.html` размером 13 063 470 байт. Все JSON, PNG, WAV и шрифт встроены; нет модульных импортов или внешних ресурсов, необходимых для игры. Пользователь открывает файл двойным щелчком, без сервера и установки зависимостей. Папка `node_modules` удалена после сборки и проверки.

В управляемом облачном Chromium навигация `file://` возвращает `net::ERR_BLOCKED_BY_ADMINISTRATOR`. Это ограничение тестовой среды. Для проверки тот же готовый HTML загружен в изолированный документ через Chrome DevTools Protocol; HTTP/HTTPS-запросы заблокированы, для теста добавлена только ссылка на состояние приложения. Запросов к сети и ошибок JavaScript не было.

Проверены загрузка 48 комнат и меню, движение, подбор оружия, выстрел мышью, бросок, перезапуск, пауза, переходы между этажами, перенос патронов и брони, возврат к машине и состояние продолжения. Все 22 встроенных звука декодированы через игровой AudioEngine. Полотна всех 48 комнат совпали попиксельно со снимками до изменений. Проверка сохранения `localStorage` при прямом открытии файла на пользовательской машине не выполнялась; существующая обработка недоступного хранилища сохранена.

Готовая пользовательская поставка содержит только `index.html` и краткую инструкцию. `src/`, `public/`, конфигурация сборки и npm-файлы нужны разработчику. Корневой HTML отмечен в `.gitattributes` как сгенерированный, чтобы встроенные библиотека и данные не искажали статистику языков GitHub.
