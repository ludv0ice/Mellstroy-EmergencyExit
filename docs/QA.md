## Поставка и ограничения проверки

Корневой `index.html` подключает отдельные CSS/JS-файлы. Изображения, шрифты и звуки остаются отдельными файлами; JSON подготовлен в `assets/data.js`, поэтому локальный запуск не требует `fetch` к JSON, сервера или сборки.

Прямой `file://` в управляемом облачном Chromium запрещён политикой браузера. Браузерные проверки выполняются через временный локальный HTTP-сервер с настоящим корневым HTML и собранными файлами. Диагностическая ссылка на приложение добавляется только сервером при проверке и не входит в поставку. Прямое открытие на пользовательском компьютере в этой среде не проверено.

Полный ZIP включает исходники, ресурсы, документацию, тесты, инструменты, корневой HTML и `dist/`. `.git`, `node_modules` и временные файлы исключаются. Проверяются CRC архива и побайтовое совпадение каждого включённого файла.
