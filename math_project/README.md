# Math Project — исправление некорректного результата

Функция `fix_wrong_result(input_text: str) -> str` принимает строку `N/M` с одним разделителем `/`. Оба числа должны лежать в диапазоне от `1` до `2_147_483_647` включительно. Для записи чисел используются цифры `0`–`9` и необязательный знак перед цифрами.

Функция удаляет пробельные символы по краям каждого числа. Если `N > M`, она возвращает `M/M`. Если `N <= M`, она возвращает `N/M` после удаления пробелов. Знак `+` и ведущие нули сохраняются.

| Вход | Результат |
| --- | --- |
| `1/10` | `1/10` |
| `251/100` | `100/100` |
| ` 9 / 10 ` | `9/10` |
| `-10/10` | `ValueError` с сообщением `Первое число должно быть положительным` |

## Структура проекта

- `app/utils/check_str.py` содержит реализацию функции. Импортировать её можно через `from app.utils import fix_wrong_result`.
- `app/main.py` запускает демонстрацию.
- `tests/test_check_str.py` содержит тесты pytest, а `tests/conftest.py` — фикстуры для случайных данных и чтения CSV.
- `tests/data/` содержит позитивные и негативные примеры. В проектной копии CSV ожидаемое сообщение для `a/b` перечисляет оба некорректных числа, как указано в задании и `GUIDE.md`.

## Установка

Для установки зависимостей нужен Python 3.11 или новее. Выполняйте команды из каталога `math_project`. Создайте виртуальное окружение.

```bash
python -m venv venv
```

Активируйте окружение в Linux или macOS.

```bash
source venv/bin/activate
```

Для командной строки Windows (`cmd.exe`) используйте следующую команду.

```bat
venv\Scripts\activate.bat
```

Установите зависимости.

```bash
python -m pip install -r requirements.txt
```

## Запуск

Запустите демонстрацию со встроенными примерами или передайте свои строки.

```bash
python -m app.main
python -m app.main "1/10" "251/100" " 9 / 10 "
```

## Тесты и покрытие

Запустите весь набор тестов или только тесты из указанного файла. Ключ `-s` выводит `print()` непосредственно в терминал.

```bash
python -m pytest -v
pytest tests/test_check_str.py -v
pytest tests/test_check_str.py -v -s
```

Для проверки покрытия строк и ветвей запустите следующую команду. HTML-отчёт будет сохранён в `coverage_re/index.html`.

```bash
python -m pytest --cov=app/utils --cov-branch --cov-report=term-missing --cov-report=html:coverage_re
```
