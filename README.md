# MELLSTROY — Emergency Exit

Браузерная игра на JavaScript и Phaser 3.

## Запуск

Распакуйте весь архив и откройте **index.html** в Chrome, Edge или Firefox. Node.js, сервер и интернет для игры не нужны. Звук включается после первого действия.

## Поставка только для игры

`npm run release` создаёт папку `release/` с готовой игрой. В ней находятся `index.html`, `src/style.css`, готовые скрипты, используемые картинки, шрифты, звуки и `LICENSES.txt`. Исходные JSON, инструменты, тесты и файлы разработки туда не копируются. Карты загружаются из `assets/data.js`.

Весь проект в репозитории сохраняет исходники для будущих правок. Игроку достаточно папки `release/`: распаковать её и открыть `index.html`.

## Структура

```text
index.html       единственная HTML-страница
assets/          картинки, звуки, шрифты, карты и готовый скрипт игры
src/             исходный JavaScript и оформление
  main.js        запуск, экраны и переходы
  simulation.js  движение, столкновения и бой
  renderer.js    отрисовка и ввод
  levels.js      подготовка и оформление уровней
  ui.js          кнопки, HUD и управление меню
  campaign.js    главы и образы
  weapons.js     оружие
  player-animation.js  анимации героя и оружия
  physics.js     геометрия и поиск пути
  tutorial.js    обучение
  cheats.js      скрытая консоль
  audio.js       звуки и музыка
  assets.js      загрузка ресурсов
  ending.js      воспроизведение катсцены
  ending-data.js события финала, титры и движение машин
  ending-art.js  отрисовка катсцены
  style.css      оформление
tools/           сборка, локальный сервер и подготовка ресурсов
tests/           автоматические проверки
docs/            описание кода, ресурсов и лицензии
package.json     команды для разработки
```

`assets/game.js` собирается из исходников. `assets/data.js` содержит подготовленные данные карт для запуска без сервера. Редактируйте файлы в `src/`, карты в `assets/rooms/` и корневой `index.html`. Путеводитель: [docs/CODE.md](docs/CODE.md).

## Управление

| Действие | Кнопка |
|---|---|
| Движение | WASD / стрелки |
| Прицел / атака | Мышь / ЛКМ |
| Подбор, смена оружия, выход | E |
| Бросок / подбор с пустыми руками | ПКМ |
| Бросок оружия | F / средняя кнопка мыши |
| Сброс рядом с собой | Q |
| Добивание оглушённого | Space |
| Взгляд вперёд | Shift |
| Перезапуск / пауза | R / Esc |
| Выбор пункта меню и паузы | W / S, Enter или мышь |

На телефоне доступны джойстик и кнопки. Уровень 00 последовательно обучает 13 действиям. Бросок оружия оглушает врага; сброшенное оружие сохраняет патроны. Между этажами ведут лестницы, выход из главы — толстая голубая дверь.

## Скрытая консоль

**F2** или **Ё/~** открывает консоль в меню, игре и паузе. Введите команду и нажмите Enter. Esc закрывает консоль, стрелки вверх/вниз перебирают историю. Пока консоль открыта, бой стоит на паузе.

| Команда | Действие |
|---|---|
| `help` | Список команд |
| `god` / `god on` / `god off` | Переключить, включить или выключить неуязвимость |
| `clear` | Зачистить текущую локацию |
| `win` | Пройти текущую локацию и перейти дальше |
| `winall` | Отметить все 22 уровня пройденными и открыть финал |
| `finale` | Посмотреть открытый финал |

Неуязвимость сохраняется при переходах и перезапусках, но выключается при перезагрузке страницы. `winall` сохраняет прохождение, сохраняя прежние рекорды.

## Финал

После прохождения всех уровней 00–21 выход из уровня 21 запускает катсцену. Меллстрой выходит из участка с детонатором, взрывает здание, садится в машину и уезжает. Во время титров машина показана сверху: она едет по трассе и обгоняет трафик под синтвейв-музыку.

После открытия финал доступен повторно из меню. Space/Enter переводит к титрам; во время титров возвращает в меню. Escape завершает просмотр.

## Разработка

Node.js нужен только для изменения и проверки игры.

```sh
npm ci
npm test
npm run build
npm run check:assets
```

`npm run build` обновляет `assets/game.js`, `assets/data.js` и копию Phaser. HTML остаётся обычным редактируемым файлом. `npm run dev` собирает игру и запускает локальный сервер; адрес выводится в терминале. После изменения JavaScript снова выполните сборку и обновите страницу браузера.

Для размещения на сайте используйте содержимое `release/`. Полный архив дополнительно содержит исходники, проверки, инструменты и документацию; `.git` и `node_modules` в него не входят.

Исходные материалы Hotline Miami принадлежат их правообладателям. Это некоммерческая фан-адаптация. Происхождение ресурсов и лицензии находятся в `docs/ORIGIN.md`, `docs/ART.md` и файлах лицензий. Результаты проверок — в [docs/QA.md](docs/QA.md).
