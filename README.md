# MELLSTROY — Emergency Exit

Локальная браузерная фан-адаптация на **HTML + CSS + JavaScript / Phaser 3**. Mellstroy пытается выбраться из города после полицейского рейда. Игровой цикл построен вокруг стремительного боя сверху, смертельных попаданий, подбора оружия и возвращения к машине.

## Запуск

Требуется Node.js. В корне проекта:

```powershell
npm.cmd install
npm.cmd run dev
```

Открыть **http://127.0.0.1:5173/**. Для готовой статической сборки:

```powershell
npm.cmd run build
npm.cmd run preview
```

Сборка находится в `dist/`; её нужно обслуживать HTTP-сервером. Открытие `index.html` через `file://` не поддерживается из-за модульных скриптов и загрузки JSON.

## Что реализовано

- 22 главы с адаптированными вступлениями, 48 уникальных комнат кампании, архив всех 159 комнат GMX; 67 комнат исходного проекта содержат боевых противников.
- Импорт исходной геометрии: координаты экземпляров, тайлы, исходные прямоугольники текстур, порядок глубины, масштаб, поворот, размеры, origin и bounding box спрайтов.
- Движение с ускорением и обходом углов по мотивам `scrPlayerMoveKeyboard.gml`; направление атаки задаётся мышью.
- 35 типов оружия и предметов, кулаки, ограниченный боезапас, обмен оружия, броски, оглушение, добивание. Темп стрельбы, разброс и число дробин базового оружия сверены с `scrPlayerShoot.gml`; ID и боезапас — с `scrCurrentWeapon.gml`, `scrGetWeapon.gml`, Create-событием `objWeapon`.
- Патруль, зрительный конус, реакция на выстрелы, поиск последней позиции, обход препятствий, ближние и вооружённые противники, собаки, усиленные противники.
- Удары дверью, разрушаемое стекло, следы боя, очки, комбо, мгновенный перезапуск, пауза и настройки.
- Состояние этажей сохраняется при переходах; оружие и патроны переносятся. После зачистки всей главы нужно вернуться к машине. Есть анимация посадки и отъезда.
- 24 варианта игровых модификаторов, адаптированных из механик масок: скорость, смертельные кулаки/двери, оружие на старте, тихие выстрелы, боезапас, броня, точность, окно комбо, обратное управление и другие.
- 75 исходных звуковых эффектов и новый процедурный синтезаторный трек. Звук включается после действия пользователя.
- Прогресс и рекорды сохраняются в `localStorage`; меню и настройки адаптируются под узкий экран. Есть экранные кнопки для сенсорного устройства; основные проверки проведены с клавиатурой и мышью.

## Граница текущего переноса

**Это рабочая версия 0.1, а не полный перенос Hotline Miami 1:1.**

159 комнат импортированы как данные. 425 GML-скриптов и события 861 объекта сохранены для сверки, но не запускаются браузером автоматически. Боевая логика переписана явно на JavaScript. Оригинальные графы сюжетных событий, катсцены, специальные фазы боссов, некоторые интерактивные декорации, секреты и вся система разблокировки оригинала ещё не перенесены. Боссы сейчас используют общую боевую модель. Геометрия и отдельные параметры оружия сохранены, однако ИИ, подсчёт очков, двери и ряд предметов используют приближённую реализацию.

Новая графика заменяет активного героя, удар кулаком, вооружённых/безоружных полицейских, тела, машину, стол стримера и атлас полов. Остальные исходные ассеты сохранены; полная замена всей мебели, NPC, окружения и анимаций оружия ещё не выполнена. [Список новых ассетов и промптов](docs/ART.md).

Архив позволяет открывать все карты, включая служебные комнаты, но наличие комнаты в архиве не означает поддержку её сценариев. Конструктор симуляции проверен для всех 67 боевых карт, каждая из них загружена в браузере. Полностью пройдены учебная глава и двухэтажная глава вокзала; полное прохождение каждой главы ещё не проверено.

## Управление

| Действие | Управление |
|---|---|
| Движение | WASD / стрелки |
| Прицел / атака | Мышь / ЛКМ |
| Подбор оружия | E / ПКМ |
| Бросок | F / средняя кнопка мыши |
| Добивание оглушённого | Space |
| Взгляд вперёд | Shift |
| Переход / посадка у отмеченного выхода | E |
| Перезапуск комнаты | R |
| Пауза | Esc |

Все главы доступны для ручного выбора; прохождение открывает маршрут продолжения и сохраняет рекорд.

## Структура

- `src/simulation.js` — симуляция, бой, ИИ и правила.
- `src/physics.js` — столкновения, пространственный индекс, навигация.
- `src/gmx.js` — адаптер данных GMX и безопасное чтение простых присваиваний GML; произвольный код не исполняется.
- `src/renderer.js` — Phaser, камера и отрисовка.
- `src/main.js` — интерфейс, кампания, переходы, сохранения.
- `src/weapons.js`, `src/campaign.js`, `src/audio.js` — оружие, главы/модификаторы и звук.
- `tools/import_gmx.py` — повторяемый импорт всего GMX.
- `tools/prepare_art.py` — нормализация сгенерированных ассетов без изменения исходных файлов.
- `public/assets/original/` — нетронутые копии исходных текстур.
- `public/assets/custom/` — новые игровые текстуры.
- `assets/generated/` — исходные результаты ImageGen.
- `docs/port-audit.json` — отчёт по комнатам и ограничениям.
- `docs/browser-rooms.json`, `docs/campaign-playtest.json` — результаты браузерной проверки.

Для повторного импорта и нормализации требуется Python с Pillow:

```powershell
python tools/import_gmx.py
python tools/prepare_art.py
node tools/audit_port.mjs
npm.cmd test
```

Размеры кадров новых ассетов, число кадров и точки привязки сравниваются с GMX и исходными файлами из `sprites`. Для исходных PNG тест сравнивает SHA-256 исходника и браузерной копии.

## Происхождение

Исходный материал — локальные `sprites/` и `HotlineMiami.gmx-master/`. README поставленного репозитория прямо говорит, что проект не является open-source и предназначен для некоммерческого использования. Исходные код и графика Hotline Miami принадлежат их правообладателям. Эта версия подготовлена как локальная некоммерческая фан-адаптация; коммерческая публикация не предусмотрена. Новые сценарные реплики являются вымышленными.
