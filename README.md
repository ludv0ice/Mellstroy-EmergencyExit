# MELLSTROY — Emergency Exit

Браузерная фан-игра на **JavaScript, Phaser 3 и Vite**. Стремительный бой сверху, подбор оружия и побег из города после полицейского рейда.

## Запуск

Для игры **не нужны Node.js, npm, сервер и интернет**. Скачайте проект или готовый архив, распакуйте и откройте корневой **`index.html` двойным щелчком** в современном Chrome, Edge или Firefox. В одном HTML-файле уже находятся код, комнаты, текстуры, звуки и шрифт. Звук включается после первого действия пользователя.

Не открывайте шаблон `src/index.html`: он предназначен для разработки. Корневой `index.html` — готовая автономная игра размером около 13,9 МБ.

## Разработка и пересборка

Node.js 18+ нужен только разработчику для изменения исходников и пересборки. В поставку игры он не входит; локальная папка `node_modules` удалена. Облачная среда проверена на Node.js 24.19.0.

```sh
npm ci
npm run dev
```

Vite запускает локальный HTTP-сервер на порту 5173. Для разработки откройте `http://127.0.0.1:5173/src/index.html`. На Windows те же команды можно вызвать через `npm.cmd`.

```sh
npm test
npm run build
npm run check:assets
npm run build:standalone
npm run preview
```

`npm run build:standalone` обновляет корневой `index.html`: данные встраиваются, модульные скрипты объединяются, внешние загрузки не нужны. Для распространения автономной версии достаточно этого одного файла. После изменения исходников пересоберите его этой командой.

`npm run build` отдельно создаёт обычную веб-сборку в `dist/` для размещения на сайте; её обслуживают HTTP-сервером. `node_modules` и `.git` не входят в полный архив; все исходники сохраняются.

## Игра

- Уровень 00 — 13 последовательных заданий: движение, прицел, кулак, добивание, подбор, сброс, повторный подбор, бросок, возврат оружия, мили-удар, дробовик, выстрел и выход. Цели отмечены стрелкой; обучение ждёт выполнения задания. Враги безопасны, а промахи и пустой магазин не требуют перезапуска.
- Все 22 главы, 48 комнат кампании и отдельная сцена главного меню.
- 35 типов оружия и предметов, броски, оглушение, добивание, двери и разрушаемое стекло.
- Мили-оружие имеет отдельные дистанции удара; белая дуга дальности не отображается. Бросок оружия в любом профиле оглушает как удар кулаком. Сброшенное или брошенное оружие можно снова подобрать с оставшимися патронами.
- Перед ближней атакой враг замахивается 0,22 с; после обнаружения ждёт 0,45 с перед первым выстрелом. Дальность, урон и скорость героя сохранены.
- Патруль, обнаружение и поиск игрока; собаки и усиленные противники.
- Сохранение состояния этажей, перенос оружия и патронов, возвращение к машине.
- 24 модификатора, очки и комбо, перезапуск, пауза, настройки и прогресс в `localStorage`.
- Клавиатура, мышь и экранные кнопки для сенсорных устройств.
- Герой остаётся вертикальным: тело следует движению, а при ударе или выстреле выбирается направление к цели. Для ходьбы и мили-атак используются отдельные кадры вниз, вверх, влево и вправо; мышь управляет прицелом без вращения всего персонажа.
- Исходные текстуры и 22 используемых звуковых эффекта без изменения качества; новые спрайты и процедурная музыка.

Архивный режим «Карты из GMX» удалён. Неиспользуемые карты, скрипты, звуки, дубли текстур и промежуточные файлы генерации исключены из текущей версии. Геометрия, параметры боя и отрисовка кампании сохранены.

## Управление

| Действие | Управление |
|---|---|
| Движение | WASD / стрелки |
| Прицел / атака | Мышь / ЛКМ |
| Подбор оружия / переход / посадка | E |
| Бросок с оружием / подбор с пустыми руками | ПКМ |
| Бросок | F / средняя кнопка мыши |
| Сброс оружия рядом с собой | Q |
| Добивание | Space |
| Взгляд вперёд | Shift |
| Перезапуск / пауза | R / Esc |

## Структура

- `src/` — редактируемый код: `main.js` управляет экранами, `simulation.js` — правилами игры, `renderer.js` — отрисовкой, `tutorial.js` — заданиями обучения. `style.css` содержит общую палитру меню.
- `index.html` — готовая автономная игра; `src/index.html` — шаблон разработчика.
- `assets/` — игровые JSON, текстуры, звуки и шрифты; дополнительной папки `public/` больше нет. `rooms.js` загружает готовые сущности; интерпретатор исходных скриптов не нужен.
- `tests/` — механики, целостность ассетов и регрессии относительно версии до сокращения.
- `tools/check-assets.mjs` — проверка состава ассетов и лимита поставки 100 МБ.
- `tools/build-standalone.mjs` — сборка автономного HTML без потери качества ресурсов.
- `tools/prepare_hero.py` и `tools/art-source/` — исходные изображения и повторяемая нормализация направленных спрайтов героя. Python с Pillow нужен только для этого шага подготовки графики.
- `docs/` — [ассеты](docs/ART.md), [проверки](docs/QA.md) и [происхождение материалов](docs/ORIGIN.md).

Структура JSON комнат: `id`, `width`, `height`, `entities`, `tiles`. Сущности содержат готовые типы, трансформации, флаги столкновений и числовые настройки. `targets`, `forward` и `backward` описывают переходы. Размеры кадров, точки привязки и маски находятся в `manifest.json`. Текстуры можно менять в `assets/`, сохраняя их размеры и метаданные; Python и редактор GameMaker для разработки игры не требуются.

Промежуточные исходники удалены из текущего дерева, но доступны в истории Git. Обычное удаление файлов не уменьшает старую историю клонирования. После отправки изменений на GitHub в текущей версии не будет GML-файлов; игровые данные отмечены как сгенерированные в `.gitattributes`.

Каждое обновление передаётся полным архивом проекта со всеми файлами, включая неизменённые: `src/`, `assets/`, `docs/`, `tests/`, `tools/`, конфигурация, корневой автономный `index.html` и веб-сборка `dist/`. История `.git`, временные файлы и `node_modules` в пользовательский архив не входят.

## Ограничения и происхождение

Версия 0.1 остаётся самостоятельной адаптацией: особые фазы боссов, исходные сюжетные события, катсцены и секреты не перенесены полностью. Боссы используют общую боевую модель. Проверки не означают полного прохождения всех глав или соответствия Hotline Miami 1:1.

Исходные материалы Hotline Miami принадлежат их правообладателям. Сохранён [README исходного архива](docs/ORIGIN.md) с указанием авторов и условий некоммерческого использования. Коммерческая публикация этой фан-адаптации не предусмотрена. Сценарные реплики вымышлены.

Ближнее оружие удерживается по направлению движения и имеет отдельный взмах или выпад. У героя дальность каждого ближнего оружия больше, чем у врагов. Голубой круг вокруг героя убран; кольца на оружии остаются.

Интерфейс использует Exo 2 с кириллицей (SIL OFL, см. `docs/FONT-LICENSE.txt`). Палитра задаётся шестью переменными в начале `src/style.css`; игровые текстуры не перекрашены. Корневой HTML создаёт сборщик из `src/` и `assets/`.
