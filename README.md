# MELLSTROY — Emergency Exit

Браузерная игра на JavaScript и Phaser 3.

## Запуск

Распакуйте **весь архив** и откройте корневой `index.html` в Chrome, Edge или Firefox. Для игры не нужны Node.js, npm, сервер и интернет. Звук включается после первого действия.

`index.html` — обычная HTML-разметка размером около 9 КБ. Он подключает CSS и отдельные JS-файлы. Папки `assets/` и `src/` должны оставаться рядом с ним.

## Структура

```text
index.html
assets/
  rooms/          карты и размещение объектов
  original/       исходные игровые спрайты
  custom/         новые спрайты
  background/     тайлы уровней
  audio/          звуковые эффекты WAV
  fonts/          шрифты
  vendor/         библиотека Phaser
  manifest.json   описание ресурсов
  data.js         подготовленные JSON-данные для локального запуска
src/
  main.js         экраны, запуск и переходы между уровнями
  simulation.js   движение, столкновения и бой
  renderer.js     отрисовка и ввод
  tutorial.js     задания обучения
  menu-navigation.js  клавиатура и мышь в меню
  level-art.js    отрисовка новых планировок
  ending.js       воспроизведение финальной катсцены
  ending-art.js   участок, взрыв, машина, трасса и титры
  ending-sequence.js  порядок сцен и условия открытия финала
  weapons.js      настройки оружия
  campaign.js     главы и образы персонажа
  cheats.js       скрытая консоль и чит-команды
  audio.js        звук и музыка
  assets.js       загрузка ресурсов
  rooms.js        подготовка комнат
  physics.js      геометрия и поиск пути
  player-animation.js
  style.css
  index.html      шаблон страницы
  game.js         подготовленный скрипт запуска
```

`assets/data.js` содержит JSON комнат и манифестов. Это позволяет открывать игру локально без запросов `fetch` к JSON-файлам. Картинки, звуки и шрифты остаются обычными отдельными файлами.

`src/game.js` собирается из модулей `src/`. Phaser подключается отдельно из `assets/vendor/phaser.js`. Комментарии удалены из кода, сведения о проекте находятся здесь и в `docs/`.

`tests/` содержит проверки, `tools/` — сборку и проверку игры, `docs/` — результаты тестирования и лицензии. `dist/` создаётся для размещения на сайте. Исходные изображения для подготовки спрайтов находятся в `tools/art-source/`.

## Новые уровни

Все 48 игровых сцен и фон главного меню получили новые планировки. Контуры помещений, маршруты, двери, укрытия, точки входа и выходы заданы заново. У помещений разное назначение, мебель и покрытие пола. Каталог и обзор всех 49 сцен — в `docs/LEVELS.md`. Между этажами ведут видимые лестницы, выход из главы оформлен утолщённой голубой дверью в стене. После зачистки нажмите E рядом с переходом. Машина и обязательный обратный путь удалены.

## Скрытая консоль

**F2** или клавиша **Ё/~** открывает консоль в меню, игре и паузе. В обычном интерфейсе она не отображается. Бой при вводе команд стоит на паузе. Введите команду на английском и нажмите Enter; Esc, F2 или Ё закрывают консоль. Стрелки вверх и вниз перебирают историю команд.

| Команда | Действие |
|---|---|
| `help` | Список команд |
| `god` | Переключить неуязвимость |
| `god on` / `god off` | Включить / выключить неуязвимость |
| `clear` | Убрать всех врагов и вражеские пули в текущей локации, открыть выход |
| `win` | Мгновенно пройти текущую локацию и перейти дальше |
| `winall` | Мгновенно отметить все 22 уровня пройденными и открыть финал |
| `finale` | Запустить открытый финал |

`god` действует до отключения или перезагрузки страницы и сохраняется при переходах и перезапусках локаций. `winall` сохраняет прохождение в браузере, не затирает прежние рекорды и возвращает в меню после закрытия консоли. В обучении `clear` снимает ограничения уроков и открывает выход. Во время катсцены консоль не открывается.

## Финал

После прохождения всех 22 уровней, включая обучение 00, выход из уровня 21 автоматически запускает финальную катсцену. В ней Меллстрой выходит из многоэтажного полицейского участка, нажимает детонатор, уезжает от взрыва и продолжает путь по ночной трассе под музыку и титры.

После открытия в главном меню появляется «СМОТРЕТЬ ФИНАЛ». Результаты прошлой версии подходят: если все уровни уже пройдены, катсцену можно открыть сразу. Кнопка «К ТИТРАМ» или Space/Enter переводит к поездке и титрам; Escape и «В МЕНЮ» завершают просмотр. Во время титров Space/Enter также возвращает в меню. Громкость музыки и эффектов берётся из настроек игры.

В титрах указаны **Ruslan Chentsov (ludv0ice)** и **Maksim Barbolin (Macan PRIME67)**. Музыка финала — отдельная оригинальная синтвейв-композиция Night Drive. Катсцена и музыка работают локально, без видеофайлов, интернета и дополнительных программ. Подробности — в `docs/ENDING.md`.

## Образы

Осталось пять вариантов:

| Образ | Особенность |
|---|---|
| MELLSTROY | Обычные параметры |
| НА ХАЙПЕ | Скорость 194 вместо 180 |
| ТОЧНЫЙ РАСЧЁТ | На 20% больше патронов при первом подборе оружия |
| ДАЛЬНИЙ БРОСОК | Бросок на 20% дальше, оглушение обычное |
| НЕ ПРЕРЫВАЙСЯ | Окно комбо 2,7 вместо 2,2 секунды |

Все начинают без оружия и брони. Смертельные кулаки, неуязвимость к собакам, бесшумная стрельба и остальные прежние варианты убраны. Обучение использует обычный образ.

## Правила и управление

На каждой боевой карте добавлено по 2–3 противника: больше на просторных картах с открытыми залами, меньше в тесных помещениях. Всего на этаже — от 3 до 9 врагов. В обучении — 3. Живые и оглушённые враги блокируют движение героя и друг друга. Через мёртвые тела можно проходить.

| Действие | Кнопка |
|---|---|
| Выбор пункта в меню и паузе | W / S, Enter |
| Движение | WASD / стрелки |
| Прицел / атака | Мышь / ЛКМ |
| Подбор / смена оружия / выход | E |
| Бросок оружия / подбор с пустыми руками | ПКМ |
| Бросок оружия | F / средняя кнопка мыши |
| Сброс рядом с собой | Q |
| Добивание оглушённого | Space |
| Взгляд вперёд | Shift |
| Перезапуск / пауза | R / Esc |

Бросок оглушает врага; оружие можно вернуть с оставшимися патронами. Перед ближним ударом у врага есть замах 0,22 с, перед первым выстрелом после обнаружения — задержка 0,45 с. Уровень 00 обучает действиям через 13 последовательных заданий. На сенсорном экране используются джойстик и кнопки действий.

## Изменение и сборка

Node.js нужен только разработчику. Он не входит в поставку игры.

```sh
npm ci
npm test
npm run build
npm run check:assets
```

`npm run build` обновляет `index.html`, `src/game.js`, `assets/data.js`, копию Phaser и `dist/`. Для изменения логики редактируйте модули в `src/`; для изменения уровней — JSON в `assets/rooms/`.

Для разработки: `npm run dev`, затем `http://127.0.0.1:5173/src/index.html`. Для проверки веб-сборки: `npm run preview`.

## Поставка и материалы

Каждое обновление передаётся полным архивом со всеми исходниками, ресурсами, тестами, документацией, конфигурацией и `dist/`. `.git`, `node_modules` и временные файлы исключаются. Нельзя переносить для игры один `index.html` без его папок.

Исходные материалы Hotline Miami принадлежат их правообладателям. Это некоммерческая фан-адаптация. Сведения о происхождении и ограничениях переноса находятся в `docs/ORIGIN.md`; лицензии Phaser и Exo 2 — в `docs/PHASER-LICENSE.md` и `docs/FONT-LICENSE.txt`. Все проверки описаны в `docs/QA.md`.

Заголовок MELLSTROY использует прежний Justice с голубым контуром, остальные надписи — Exo 2. Клавиатура меню работает вместе с мышью; выбор главы и подтверждение старта также доступны через W/S и Enter.
